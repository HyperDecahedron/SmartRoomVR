# T-Press SmartRoomVR

T-Press is a hands-free VR interaction system that uses tongue gestures detected through EMG sensors and the OpenBCI Cyton Board. The project combines machine learning, Python, and Unity to allow users to interact with a virtual smart room environment using tongue pressure movements.

Users can perform actions such as:
- Opening and closing doors or drawers
- Turning lights on and off
- Controlling a TV
- Triggering interactions without using their hands

The system works by:
1. Collecting EMG signals from tongue muscle activity
2. Training a machine learning model for each individual user
3. Detecting real-time gesture predictions.
4. Triggering VR interactions inside the Meta Quest environment

## Technologies
- Unity
- Python
- OpenBCI Cyton Board and sensors
- Electrodes
- Meta Quest 2 or 3
